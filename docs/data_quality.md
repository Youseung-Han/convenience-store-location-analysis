## 보관본 확보 후 실행되는 검사

- 원자료에서 `분기 × 상권 × 업종`의 키 결측과 중복을 차단한다. 상권의 이름·유형을 확인하고, 전분기 대비 상권 코드의 출현·누락과 같은 이름의 복수 코드 및 동일 코드의 이름·유형 변화를 보고한다. 코드 간 임의 연결 없이 관측된 코드로 비교한다. 새 코드 또는 누락 자체는 행정적 재코딩을 입증하지 않는다.
- 상권별 편의점 매출·점포 테이블의 결합률을 양쪽 분모로 보고한다. 점포 수 0, 점포 수 결측, 매출 결측은 항목별로 집계하며 서로 겹칠 수 있다. 타깃 제외 건수는 행 단위로 한 번만 센다. 관측된 매출 0과 결측은 별도로 취급한다.
- 목표 분기 시작 시 `t-2`까지 이용 가능하다고 가정한다. 2022Q1의 학습 라벨 상한은 2021Q3, 2022Q2는 2021Q4, 2022Q4는 2022Q2다. 보관본의 분기별 공개 이력이 확보되면 지연 가정을 다시 확인한다. 두 분기보다 더 늦게 제공된 근거가 확인되면 `--lag`를 늘리고 학습 가능한 과거 분기가 남는지 검토한다.
- 모델 입력과 예측 후보 등록에는 과거 분기의 기록만 사용한다. 목표 분기 매출과 점포 수는 타깃 산출에 쓰며, 평가 지표는 같은 관측 타깃 표본에서 계산한다. WAPE는 절대 오차 합을 실제값 절댓값 합으로 나눈 백분율이다. Spearman은 표본의 값 또는 예측이 상수이면 비어 있다.
- 예측은 상권 코드와 유형으로 영역에 결합한다. 공간 후보 결합률의 분모는 자치구의 영역 파일 상권 수다. 후보 10개 이상을 확보한 자치구에서 결합률, 후보 수, 자치구 코드 순으로 선택한다. 예측이 없는 상권 대표점도 수요 지점에는 포함한다.
- 편의점 외 업종의 거래 건수 가중치는 과거 같은 분기에서 집계한다. 업종별 거래 건수의 결측은 보존하고, 전체 수요점에 유효한 가중치가 결합될 때만 사용한다. 거래건수는 관측된 상업활동의 대리지표이며 사람 수와 단위가 다르다.
- MILP 종료 상태와 선택 개수를 확인하고, 선택 지점의 합집합에서 B 최대 커버리지와 C 하한 충족 여부를 다시 계산한다. 커버리지가 동일한 B 해 중에는 예측 지표 합이 높은 조합을 선택한다. 3개 거리와 3개 출점 규모에 대해 A, B, C의 세 하한을 계산해 45개 결과를 작성한다.

테스트는 예시 자료로 시차·결합 키·후보 필터·중복 커버·제약 조건을 검사한다. 테스트 표본의 성능과 조합 수치는 실데이터 결과로 집계하지 않는다.

재현 검증에서 새 디렉터리로 포털 ZIP을 다시 받아 실행했다. `data_quality.json`, `run_status.json`, `area_validation.png`의 SHA-256이 첫 실행과 모두 일치했다. `--require-full`은 미실행 상태를 종료 코드 2로 반환했고, 단위 테스트 12개와 `pip check`가 통과했다.
